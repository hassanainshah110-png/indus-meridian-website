# Indus Meridian Enterprises — Website Starter

This is a responsive, multi-section static website for Indus Meridian Enterprises (IME).

## Files
- `index.html` — website content and sections
- `style.css` — responsive design
- `script.js` — mobile menu, product shortcuts, inquiry form behavior

## Important before publishing
1. Open `script.js`.
2. Replace `REPLACE_WITH_YOUR_BUSINESS_EMAIL` with the email address you want public.
3. Update the business location if needed in `index.html`.
4. Add your own product photos, real specifications, and verified contact details.
5. Test the website and inquiry form.

The inquiry form currently prepares an email using the visitor's email app. It does not store submissions or send them to a server. If the email placeholder has not been replaced, it displays a reminder instead.

## View locally
Double-click `index.html` to open it in a browser.

## Publish for free
This is a static HTML website and is not directly importable into Google Sites. One free hosting option is GitHub Pages:
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository, for example `indus-meridian-website`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder if you add images.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will be similar to `https://YOUR-USERNAME.github.io/indus-meridian-website/`.

GitHub may change its interface. A custom domain is optional and costs money; the GitHub Pages address is free.

## Claims and accuracy
The content avoids claiming certifications, confirmed stock, export approvals, or a specific export track record. Only publish claims that you can substantiate.
